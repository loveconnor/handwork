# Provider marks

Bundled from the providers' own websites:

- `pi.svg`: [Pi](https://pi.dev/), hero logo (without its outer whitespace).
- `omp.svg`: [omp](https://omp.sh/), navigation mark in monochrome to inherit the UI color.
- `fx.svg`: [fx](https://fx.sh/), logo glyph without the website's shimmer animation.

Other provider marks come from `@lobehub/icons-static-svg` or `honestui/logos`.
